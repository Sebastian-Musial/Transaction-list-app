# Transaction list app - CLI

# WERSJA ROBOCZA

## Cel
Aplikacja konsolowa służąca do zarządzania listą transakcji z funkcjonalnościami pozwalającymi na łatwiejszą analizę transakcji.

Podstawowe funkcjonalności:
- Wyświetlanie pełnej listy transakcji 
- Wyświetlanie pojedyńczych transakcji
- Dodawanie transakcji
- Kasowanie transakcji
- Modyfikacja transakcji

Funkcjonalności do analizowania listy transakcji:
- Sortowanie
- Filtrowanie
- Agregacja 



## Opis 
Aplikacja pozwala użytkownikowi na zarządzanie listą transakcji z możliwością dodawania i modyfikowania obecnych transakcji.
Dodatkowe funkcjonalności pozwalają na na dokonywanie dokładniejszego analizowania transakcji poprzezy metody sortowania, filtrowania oraz agregowania poszczególnych składników listy jak np. sumowanie wszystkich transakcji.

Użytkownik będzie mógł korzystać z funkcjonalności aplikacji poprzez czytelne menu w konsoli programu.
